Accessibility Analysis:

Perceivable:
- Images were missing alt text in early versions of the site.
- Contrast between some text and backgrounds was not verified.
- Changes made: Added descriptive alt attributes to all images across
  all pages. Reviewed color pairings to ensure readable contrast.

Operable:
- No skip navigation link existed, forcing keyboard users to tab
  through all nav links on every page load.
- No visible focus indicator on links or buttons.
- Changes made: Added a Skip to Main Content link at the top of every
  page. Added a CSS focus ring on all links and buttons so keyboard
  users can see where they are on the page.

Understandable:
- Navigation was inconsistent in early versions of the site.
- Placeholder lorem ipsum text was used instead of real content.
- Changes made: Applied a consistent nav structure across all pages.
  Replaced placeholder text with real content where possible.

Robust:
- Missing closing div tags caused broken layouts across multiple pages.
- normalize.css was not loaded, causing inconsistent rendering across
  browsers.
- Breakpoints were set to incorrect values (767px, 1023px) instead of
  the required 590px and 790px.
- Changes made: Fixed all missing closing tags so HTML is valid.
  Added normalize.css as the first stylesheet on every page. Corrected
  breakpoints to 590px and 790px as specified in the assignment.
